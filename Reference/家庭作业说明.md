## 家庭评估 – OCR 端点挑战 (/ocr)

## 1. 概述

Fullerton Health 的工程团队每天处理数千份医疗文件。在此家庭作业评估中，您需要设计并构建一个 HTTP 端点，该端点执行光学字符识别 (OCR)，自动检测文档类型，并返回结构化的 JSON 负载，其中包含下游理赔审核所需的关键数据字段。

本次练习旨在评估您在以下方面的技能：

- 文档分类与信息提取（传统方法 / 机器学习 / 深度学习 — 任选一种）
- API 与微服务设计
- 整洁、可维护的代码及自动化测试
- 书面沟通能力（README / 代码注释）

## 2. 功能需求

### 2.1 端点

| 方法 | 路径 | 描述 |
| --- | --- | --- |
| POST | /ocr | 接受文档图片/PDF 并返回提取结果 |

### 2.2 支持的文档类型

| 内部代码 | 可读标签 |
| --- | --- |
| referral_letter | 转诊信 |
| medical_certificate | 医疗证明 |
| receipt | 收据 |

服务必须正确识别提供的文件属于这三种类型中的哪一种。如果文档类型不在此列表中，则返回 HTTP 422，并附带消息 "unsupported_document_type"。

### 2.3 字段提取

对于每种识别的类型，按以下命名精确提取字段。除非另有说明，缺失或无法解析的值应返回 `null`。

#### 2.3.1 转诊信

| 键名 | 描述 |
| --- | --- |
| claimant_name | 患者姓名 |
| provider_name | 供应商/实验室名称（不得包含字符串 "Fullerton Health"） |
| signature_presence | 如果检测到手写签名为 `true`，否则为 `false` |
| total_amount_paid | 整数，去除所有货币符号、分隔符和小数 |
| total_approved_amount | 同上规则 |
| total_requested_amount | 同上规则 |

#### 2.3.2 医疗证明

| 键名 | 描述 |
| --- | --- |
| claimant_name | 申请人姓名 |
| claimant_address | 地址 |
| claimant_date_of_birth | DD/MM/YYYY |
| diagnosis_name | 诊断 |
| discharge_date_time | DD/MM/YYYY |
| icd_code | ICD 代码 |
| provider_name | 供应商/实验室名称（不得包含 "Fullerton Health"） |
| submission_date_time | 入院日期时间（DD/MM/YYYY） |
| date_of_mc | MC 日期（DD/MM/YYYY） |
| mc_days | MC 天数（整数） |

#### 2.3.3 收据

| 键名 | 描述 |
| --- | --- |
| claimant_name | 申请人姓名 |
| claimant_address | 地址 |
| claimant_date_of_birth | DD/MM/YYYY |
| provider_name | 供应商/实验室名称（不得包含 "Fullerton Health"） |
| tax_amount | 整数，去除所有分隔符和小数 |
| total_amount | 整数，去除所有分隔符和小数 |

## 3. API 契约

### 3.1 请求

```
POST /ocr
Content-Type: multipart/form-data
file=<binary document>
```

接受 PDF 和常见图片格式（JPG/PNG）。

### 3.2 成功响应（HTTP 200）

```json
{
  "message": "Processing completed.",
  "result": {
    "document_type": "referral_letter",
    "total_time": 3.04,
    "finalJson": {
      "claimant_name": "…",
      "provider_name": "…",
      "signature_presence": true,
      "total_amount_paid": 3000000,
      "total_approved_amount": 3000000,
      "total_requested_amount": 3000000
    }
  }
}
```

*各阶段耗时字段为可选，但有则更好。*

### 3.3 错误响应

| 状态码 | 条件 | 示例响应体 |
| --- | --- | --- |
| 400 | 缺少文件 / 无效 MIME 类型 | `{ "error": "file_missing" }` |
| 422 | 不支持的文档类型 | `{ "error": "unsupported_document_type" }` |
| 500 | 未处理的异常 | `{ "error": "internal_server_error" }` |
